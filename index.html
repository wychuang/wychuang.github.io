03

MODEL EVALUATION / 2026

AI 搜索
回答评测

CASE FILES / REVIEWABLE

把“这个回答感觉不对”继续拆解为时效、来源、证据绑定、任务完成度和表达问题。

评测结构设计 13 分评分标准，用“已核验 / 证据不全 / 待绑定”标记样本状态，保留原回答、评分、来源、截图与修改理由。

可复查结果复审 17 条候选案例，形成 11 组回答偏好对；证据不足的样本留在待补状态，不进入合格集。

ONE REAL CASE

某 API 问答同时出现旧模型名、过时参数和泛化文档入口。我将问题定位到信息过期、官方来源缺失和证据绑定不足，补入可定位的官方证据后重写优选回答。

多模态补充：另复审 12 条本人唇语识别项目中的图表与公式样例，按图片、题目、答案和推理过程逐项检查，得到 5 条通过、4 条部分通过、3 条拒绝。
